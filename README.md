 Water Billing System

## Description
This is a Water Billing System that helps manage customer water consumption and generate bills automatically.

## Features
- Add new customers
- Record water meter readings
- Calculate bills based on consumption
- Generate billing reports
- Store customer information

## Installation
1. Clone this repository
2. Navigate to the src folder
3. Run: python main.py

## Usage
Run the main.py file and follow the menu options to:
- Register new customers
- Enter meter readings
- Generate bills
- View reports
